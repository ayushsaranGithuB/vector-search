# ✅ Completed — E2E Pipeline

The full ingestion pipeline is implemented and working:

1. ✅ User uploads a PDF → `POST /uploads` creates source + presigned URL
2. ✅ File is saved to Cloudflare R2 → `POST /uploads/{id}/upload` (direct PUT) or `POST /uploads/{id}/finalize` (backend upload)
3. ✅ Task is added to Queue for ingestion into Pinecone → CloudAMQP `ingestion` exchange
4. ✅ Document metadata shows up in admin dashboard as "under processing" → auto-polling every 5s
5. ✅ A worker reads the queue and grabs the PDF, chunks and encodes it using Pinecone Inference into the correct project namespace
6. ✅ When the task is completed it is cleared from queue → message acknowledged
7. ✅ The PDF appears in dashboard as ready source → status = PROCESSED
8. ✅ Search works on frontend and can use this source for citations → hybrid search (vector + keyword)
