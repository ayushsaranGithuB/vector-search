# Vector Search Demo

Demonstration of a production level Vector Search Pipeline built with open-source tools

## Features

• Highlight the exact retrieved text.
• Show cosine similarity scores.
• Explain why each chunk was selected.
• Compare embedding models.
• Toggle between keyword, vector, and hybrid search.
• Show latency for each stage.
• Visualise embeddings with UMAP or t-SNE.
• Display the retrieval pipeline (query → embedding → retrieval → rerank → generation).
• Include an "unsupported claim" detector that flags generated sentences without supporting citations.
